# Иллюстрации Ардена

Эти изображения созданы специально для «Цены власти» и включаются в игру локально. Внешние изображения, шрифты, сервисы и запросы для их показа не нужны.

- `arden-panorama.png` — панорама княжества, 1672 × 941: долина, река, мост, сады, город и замок. Замок расположен справа; для надписи слева используйте затемняющий градиент, не меняя исходник.
- `court-portraits.png` — портретный атлас 1536 × 1024, три столбца и две строки. Каждая ячейка — 512 × 512 пикселей, без промежутков.

| Персонаж | Позиция в атласе | CSS background-position |
|---|---|---|
| Мирена Вель, казначей | слева сверху | `0% 0%` |
| Борис Грей, воевода | по центру сверху | `50% 0%` |
| Лада Рейн, лекарка | справа сверху | `100% 0%` |
| Ильмар Вейд, мастер дорог | слева снизу | `0% 100%` |
| Сава Лир, посланник | по центру снизу | `50% 100%` |
| Вера Торн, наместница | справа снизу | `100% 100%` |

Для одного портрета: `background-size: 300% 200%`. Атлас изображает шесть разных людей; имя и роль остаются обычным доступным текстом интерфейса.
