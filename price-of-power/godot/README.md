# Godot-версия «Цены власти»

Первый технический каркас вертикального среза.

## Запуск

```bash
godot4 --path godot --editor
```

Или сразу игру:

```bash
godot4 --path godot
```

## Проверка

```bash
godot4 --headless --path godot --script res://tests/test_runner.gd
```

Сейчас реализованы:

- запускаемая 3D-сцена укреплённой столицы;
- камера с перемещением, вращением и масштабированием;
- шесть месяцев по три периода;
- раздельные государственная и семейная казна;
- первый набор ресурсов;
- переходы периода;
- JSON-сохранение и загрузка;
- выбор ключевых зданий непосредственно в 3D-городе;
- плавный фокус камеры и контекстная сцена объекта;
- первое дело о нехватке зерна;
- четыре способа делегировать расследование с разными сроками и сведениями;
- headless-тесты основных инвариантов.

Геометрия города пока является техническим блокингом и будет заменяться через отдельные сцены, не меняя симуляцию.
