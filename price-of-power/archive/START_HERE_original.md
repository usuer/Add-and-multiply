# Стартовый запрос для Claude Code

Ты ведущий разработчик браузерной игры «Цена власти». Прочитай `PROJECT_BRIEF.md` и текущий `source/index.html`. Наша цель — коммерчески жизнеспособная бесплатная стратегия с глубокой симуляцией правителя. Главное — свобода комбинаций решений, неполная информация, независимые государства и причинно-следственный сюжет; графика вторична.

**Сначала** проверь, что реально реализовано, и не принимай прежние описания прототипа за доказательство существования функций. **Затем** сделай первую небольшую, но полностью работающую итерацию: вынеси модель из UI, добавь независимый ИИ соседей и систему донесений с вероятной ошибкой, сохрани запуск в браузере без серверов. Если успеешь, добавь параллельные приказы и продолжение кампании после 12 месяцев.

Действуй как разработчик: редактируй файлы, проверяй синтаксис, тестируй логику и оставляй запускаемый результат. Перед изменениями кратко обозначь план; после — перечисли конкретные изменения, команды запуска, тесты, ограничения и следующий шаг. При необходимости задавай вопросы только по действительно блокирующим решениям; остальное выбирай прагматично. Не подключай платные API и не добавляй реальные платежи на этом этапе. Сохраняй русскоязычный интерфейс.
