# Цена власти — документы Godot-версии

Рабочий комплект GDD 0.1:

1. [Игровой цикл демоверсии](GDD_01_GAME_LOOP.md)
2. [Архитектура Godot 4](GDD_02_GODOT_ARCHITECTURE.md)
3. [Модели данных](GDD_03_DATA_MODELS.md)
4. [План вертикального среза](GDD_04_VERTICAL_SLICE_PLAN.md)

Документы основаны на согласованном предпроизводственном интервью. Они описывают новую десктопную игру; существующий HTML-прототип остаётся справочником проверенных идей, но не является архитектурной основой интерфейса.

Перед созданием проекта требуется отдельное утверждение технических решений, перечисленных в конце плана вертикального среза.
